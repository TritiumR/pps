# weight -- deterministic stand-in for a GPT-4o ReKep response.
# Format follows rekep/prompts/prompt_template.txt, so _render() parses it exactly as
# rekep/constraint_generation.py parses a live response. Placeholders in braces are the values only
# resolvable at runtime: keypoint indices from the live scene and offsets measured from the
# observed point cloud.
#
# Task: "put pear and apple on the scale"
#
# The task involves six stages:
# 1. Grasp the pear.
# 2. Lift the pear clear of the board.
# 3. Place the pear on the scale.
# 4. Grasp the apple.
# 5. Lift the apple clear of the board.
# 6. Place the apple on the scale.
#
# Stages 2 and 5 are explicit lifts. They carry no grasp or release keypoint, so the `template`
# compiler would drop them and inject its own hand-coded lift instead; under the `_vlm` compiler
# they become `move` stages whose sub-goal constraint gates advancement. Without them the plan
# advances to transport on grasp proximity alone and discovers mid-carry that the hand is empty
# (measured: 21 of 23 backtracks were "empty hand").

    """Align the end-effector with the pear (keypoint {p})."""
    return np.linalg.norm(end_effector - keypoints[{p}])

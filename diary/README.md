# diary

Progress notes and write-ups for this repo, written on request.

## Convention

- One Markdown file per entry, named `YYYY-MM-DD-<short-slug>.md` (e.g. `2026-06-23-pot-lid-fix.md`).
  Multiple entries on the same day are fine — distinguish them by slug.
- Each entry starts with a `#` title and a one-line date/summary, then whatever is relevant:
  what was done, why, findings, decisions, open questions, next steps.
- Entries are written **on request** ("write this up in the diary" / "add a diary entry for X").
- This is a human-readable log, not a substitute for commit messages or code comments.
